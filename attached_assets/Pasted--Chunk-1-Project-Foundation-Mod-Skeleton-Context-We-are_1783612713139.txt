#### `build.gradle` requirements:
- Forge MDK 1.12.2 standard format
- Group: `com.airarsenal`
- Version: `1.0.0`
- Mappings: `stable_39` (last stable for 1.12.2)
- No extra dependencies beyond Forge

#### `AirArsenal.java` requirements:
- `@Mod` annotation with modid, name, version
- `@SidedProxy` for CommonProxy / ClientProxy
- `@EventBusSubscriber` inner setup class
- `preInit`, `init`, `postInit` lifecycle methods
- Each lifecycle method calls the matching proxy method
- Logger via `LogManager.getLogger`

#### `ModItems.java` requirements:
- `@ObjectHolder("airarsenal")` on the class
- Empty for now — just the class with a `register(IForgeRegistry<Item> registry)` method stub
- `@SubscribeEvent` on the register method

#### `ModBlocks.java` requirements:
- Same pattern as ModItems but for Block registry

#### `ModEntities.java` requirements:
- Static `register()` method — empty for now
- Comment block listing all entities that will be registered in future chunks:

#### `AirArsenalTab.java` requirements:
- Extends `CreativeTabs`
- Tab icon: `Items.IRON_INGOT` as placeholder (will be replaced later)
- Label: `"Air Arsenal"`

#### `mcmod.info` requirements:
- All standard fields filled in
- Description: `"Planes, bombs, guided missiles, artillery, and tactical aerial combat for Minecraft 1.12.2"`
