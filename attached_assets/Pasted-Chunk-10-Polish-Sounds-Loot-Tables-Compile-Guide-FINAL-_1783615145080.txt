#### Loot tables for non-craftable items:
In Forge 1.12.2 custom loot table injection is done by subscribing to `LootTableLoadEvent` — NOT via `data/` folder (that is 1.16+ datapack format). Create `LootTableHandler.java` at `com.airarsenal.event` and register it on the Forge event bus. In the event handler, call `event.getTable().addPool(...)` to inject a new `LootPool` containing a `LootEntryItem` (no kill condition needed — weight alone controls rarity). Use the `LootTables.*` constants for table names. **Do NOT use `LootConditionKilled`** — that class doesn't exist in 1.12.2; use conditions-free pools:

```java
@SubscribeEvent
public void onLootTableLoad(LootTableLoadEvent event) {
    if (event.getName().equals(LootTables.CHESTS_END_CITY_TREASURE)) {
        event.getTable().addPool(buildPool(ModItems.SPAWN_EGG_FIGHTER_JET, 1));
    }
    // ... etc.
}

private LootPool buildPool(Item item, int weight) {
    return new LootPool(new LootEntry[]{ new LootEntryItem(item, weight, 0, new LootFunction[0], new LootCondition[0], "airarsenal_inject") }, new LootCondition[0], new RandomValueRange(1), new RandomValueRange(0), "airarsenal_pool");
}
```

Valid 1.12.2 loot table constants (all under `net.minecraft.world.storage.loot.LootTables`):
- `CHESTS_END_CITY_TREASURE`, `CHESTS_WOODLAND_MANSION`, `CHESTS_STRONGHOLD_LIBRARY`, `CHESTS_STRONGHOLD_CORRIDOR`, `CHESTS_DESERT_PYRAMID`, `CHESTS_NETHER_BRIDGE`, `CHESTS_ABANDONED_MINESHAFT`, `CHESTS_VILLAGE_BLACKSMITH`
