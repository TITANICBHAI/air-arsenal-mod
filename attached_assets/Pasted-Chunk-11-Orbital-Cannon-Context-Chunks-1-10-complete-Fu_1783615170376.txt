Chunk 11 — Orbital Cannon

### Context
Chunks 1–10 complete. Full air combat system, artillery, missiles, advanced planes, and all polish pass done.

This chunk adds the **Orbital Cannon** — the mod's most powerful and most expensive weapon. It is a placeable multiblock structure that communicates with a fictional satellite and drops a kinetic tungsten rod from y=300 onto a player-designated target. It has a 5-minute cooldown, requires a craftable uplink card per shot, and broadcasts a visible warning to all nearby players before impact.

It is inspired by the GDI Ion Cannon (Command & Conquer), the Rods from God concept, and the call-in killstreak feeling of COD.

#### Multiblock structure layout (top-down view, F = Frame, C = Core):
```
  F
F C F
  F
```
Core is placed first. Frame blocks placed in the 4 cardinal adjacent positions (same Y level). The cannon only activates when all 4 frame blocks are present.

#### Charge state machine:
```
IDLE → (player presses FIRE in GUI, uplink card consumed) → CHARGING (200 ticks)
     → WARNING (100 ticks, warning marker spawned at targetPos)
     → FIRING (OrbitalRodEntity spawned at targetPos x/z, y=300)
     → COOLDOWN (6000 ticks = 5 minutes)
     → IDLE
```

#### Create `OrbitalCannonTileEntity.java` at `com.airarsenal.block`
Extends `TileEntity` + implements `IInventory` (single slot for `ItemSatelliteUplinkCard`).

Fields:
- `targetPos` (BlockPos) — set when GUI confirms fire
- `chargeState` (enum: IDLE, CHARGING, WARNING, FIRING, COOLDOWN)
- `stateTicks` (int) — ticks elapsed in current state
- `cooldownTicks` (int) — counts down from 6000

`update()` (server side only — `if (world.isRemote) return;`):
1. **IDLE**: do nothing — wait for `PacketOrbitalFire` to arrive
2. **CHARGING**: increment `stateTicks`; at 200 ticks → transition to WARNING; play `weapon.orbital.charge` sound on transition
3. **WARNING**: spawn `OrbitalWarningMarkerEntity` at `targetPos` on first tick; send `PacketOrbitalWarning(targetPos, 100)` to all players within 200 blocks; at 100 ticks → transition to FIRING
4. **FIRING**: spawn `OrbitalRodEntity` at (`targetPos.x + 0.5`, `300`, `targetPos.z + 0.5`); play `weapon.orbital.fire` sound; transition to COOLDOWN
5. **COOLDOWN**: decrement `cooldownTicks`; at 0 → transition to IDLE

Structure validation (called every 40 ticks while IDLE or COOLDOWN):
```java
private boolean validateStructure() {
    BlockPos[] required = { pos.north(), pos.south(), pos.east(), pos.west() };
    for (BlockPos p : required) {
        if (!(world.getBlockState(p).getBlock() instanceof OrbitalCannonFrameBlock)) return false;
    }
    return true;
}
```
If structure invalid: remain IDLE and cannot accept fire command.

NBT: read/write `targetPos`, `chargeState` (as int ordinal), `stateTicks`, `cooldownTicks`.

#### Create network packets — register in `ModNetwork.java` with IDs 9, 10, 11, 12:
```java
INSTANCE.registerMessage(PacketOrbitalFire.Handler.class,    PacketOrbitalFire.class,    9,  Side.SERVER);
INSTANCE.registerMessage(PacketOrbitalWarning.Handler.class, PacketOrbitalWarning.class, 10, Side.CLIENT);
INSTANCE.registerMessage(PacketOrbitalImpact.Handler.class,  PacketOrbitalImpact.class,  11, Side.CLIENT);
INSTANCE.registerMessage(PacketScreenShake.Handler.class,    PacketScreenShake.class,    12, Side.CLIENT);
```

Packet definitions:
- `PacketOrbitalFire(BlockPos cannonPos)` — client → server
  - Server handler: look up `OrbitalCannonTileEntity` at `cannonPos`; if IDLE + structure valid + uplink card present + target set: consume uplink card, set state to CHARGING
- `PacketOrbitalWarning(BlockPos targetPos, int ticksToImpact)` — server → client, sent to all players within 200 blocks
  - Client handler: store `warningTargetPos` + start 100-tick warning sound loop (`weapon.orbital.warning`); optionally render a red X at `targetPos` in world space via `RenderWorldLastEvent`
- `PacketOrbitalImpact(BlockPos targetPos)` — server → client, sent to all players within 300 blocks on impact
  - Client handler: trigger 30-tick screen shake + 1-tick full-white screen flash; play `weapon.orbital.impact` sound
- `PacketScreenShake(float intensity, int durationTicks)` — server → client (general purpose)
  - Client handler: store in `ScreenShakeHandler` singleton; `EntityViewRenderEvent.CameraSetup` listener applies random pitch/yaw offset scaled by `intensity * (remaining / duration)`, decaying linearly

#### Create `OrbitalRodEntity.java` at `com.airarsenal.entity.projectile`
Extends `Entity`. Spawned at (`targetX`, `300`, `targetZ`).

Fields:
- `targetX`, `targetZ` (double) — ground target; rod falls straight down, no horizontal drift
- `lifetimeTicks` (int)

`onUpdate()` (server-side):
- Move: `motionY = -8.0` (constant fall, 8 blocks/tick)
- Apply motion: `posY += motionY`
- Collision check: if `world.getBlockState(new BlockPos(posX, posY, posZ)).getMaterial() != Material.AIR` OR `posY <= targetY`:
  - Call `onImpact()`
- Failsafe: if `lifetimeTicks > 80` (fell 640 blocks) and still no collision: self-destruct at current pos

`onImpact()`:
1. Crater generation — sphere radius from config (`orbitalBlastRadius`, default 15): iterate and remove non-bedrock blocks; place Obsidian ring at outermost shell (8-block radius ring, 1-block thick)
2. `world.createExplosion(null, posX, posY, posZ, orbitalBlastRadius, AirArsenalConfig.orbitalBlockDestruction)` — entity/block damage
3. Spawn fire at crater rim: iterate 20 random positions within 20 blocks, `world.setBlockState(pos, Blocks.FIRE.getDefaultState())`
4. Send `PacketOrbitalImpact(new BlockPos(posX, posY, posZ))` to all players within 300 blocks via `PacketScreenShake(1.5f, 30)`
5. `setDead()`

#### Create `OrbitalWarningMarkerEntity.java` at `com.airarsenal.entity`
Extends `Entity`. Invisible (no renderer). Lives 100 ticks exactly.

`onUpdate()` (server-side, `!world.isRemote`):
- Every tick: spawn red particle ring using `WorldServer#spawnParticle` (which propagates to nearby clients automatically; `World#spawnParticle` is client-only and silently does nothing on a dedicated server):
  ```java
  if (world instanceof WorldServer) {
      WorldServer ws = (WorldServer) world;
      for (int i = 0; i < 16; i++) {
          double angle = (2 * Math.PI / 16) * i;
          double px = posX + 10 * Math.cos(angle);
          double pz = posZ + 10 * Math.sin(angle);
          ws.spawnParticle(EnumParticleTypes.REDSTONE, px, posY + 1, pz, 1, 0, 0, 0, 0);
          ws.spawnParticle(EnumParticleTypes.FLAME,    px, posY + 1, pz, 1, 0, 0, 0, 0);
      }
  }
  ```
- At tick 100: `setDead()`

#### Create `ScreenShakeHandler.java` at `com.airarsenal.client`
Plain singleton class, registered on `MinecraftForge.EVENT_BUS` in `ClientProxy.init()`.
- Stores: `float intensity`, `int durationTicks`, `int remainingTicks`
- `@SubscribeEvent` on `EntityViewRenderEvent.CameraSetup`:
  ```java
  if (remainingTicks > 0) {
      float t = (float) remainingTicks / durationTicks;
      float offset = intensity * t * (world.rand.nextFloat() - 0.5f) * 2f;
      event.setPitch(event.getPitch() + offset);
      event.setYaw(event.getYaw()   + offset * 0.5f);
      remainingTicks--;
  }
  ```
